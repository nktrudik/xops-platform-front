# MWS identity

The square MWS logo is the official compact header variant from [mws.ru](https://mws.ru/), retrieved on 26 October 2026. It is the MTS Web Services mark, not MWS AI.

The SVG paths, viewBox, proportions and original `#ff0032` brand color are unchanged. Only the website's CSS class and Vue scope attribute were removed. The same artwork is used in `public/favicon.svg`.

This compact official variant omits the small “МТС Web Services” caption found in the full-size reference. The accessible name provides that expansion. Interface accents retain XOps' `#E30611` primary color.
