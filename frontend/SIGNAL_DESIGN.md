# XOps Signal

Полировка существующего интерфейса в `feature/ui-redesign-v2`. Backend, HTTP-контракты, CI/CD, Kubernetes и зависимости не менялись.

## Композиция и границы компонентов

- `CatalogHero.vue`: графитовый hero около 340–350 px на desktop, фирменная типографика, поиск и фактические счётчики. На мобильном убран второстепенный рекламный текст, чтобы оставить место взаимодействию.
- `CatalogSignal.vue`: владеет выбранным Copilot, переключением, Escape, паузой и жизненным циклом наблюдателей. Данные получает через props из текущего каталога.
- `SignalConstellation.vue`: орбиты, ядро, узлы и подсветка выбранной связи. Никаких фиктивных связей с внутренними системами. SVG и CSS, без Canvas/WebGL и зависимостей.
- `SignalInspector.vue`: отдельная информационная область рядом со схемой на desktop и под ней на мобильном. Её размер не зависит от выбранного Copilot; описание прокручивается и доступно с клавиатуры. Перекрытие содержимого при crossfade ограничено самой панелью, орбиты и управление не перекрываются.
- `signal-layout.ts`: раскладка максимум пяти доступных Copilot из конца текущего порядка API. Дата создания не входит в контракт, поэтому это последние записи каталога, а не хронологическая сортировка. Выбранный в панели доступный инструмент вне пятёрки временно занимает последний слот; оставшиеся узлы сохраняют позиции. Порядок основного каталога не меняется.
- `CopilotCollection.vue`: прежний TransitionGroup с появлением и FLIP-перестановкой в сетке/списке. Карточки единообразны, используют реальные имя, описание, иконку, статус и формат. Усилены контраст, иерархия, hover/focus и действие открытия.
- Sidebar и header: более читаемые подписи, выраженный активный раздел, согласованные красные интерактивные акценты. Общие токены применяются также к чату и Embedded UI.

Все рабочие данные и форматы берутся из существующего API. Поиск, фильтры и вид сохраняются в URL. Command Palette, авторизация, чат, история, удаление диалогов и iframe сохраняют прежнюю логику.

## Взаимодействие с Signal

- Hover или фокус выделяет узел, деликатно приглушает остальные и показывает его информацию.
- Tab проходит по ссылкам; стрелки в схеме переводят фокус между узлами. Escape сбрасывает выбор, в том числе после наведения мышью без фокуса.
- Клик/тап по узлу открывает существующий маршрут Copilot. Кнопки «Предыдущий» и «Следующий» циклически проходят по всей текущей выборке каталога, включая инструменты за пределами орбиты и недоступные записи. Счётчик показывает положение среди всех записей. Красная кнопка открывает приложение; недоступный инструмент показывает свой статус без действия открытия.
- Смена текста происходит через crossfade в зарезервированной области. Уходящее содержимое становится inert и скрывается от скринридера; ARIA связывает выбранный узел с информацией.
- Поиск показывает в схеме только совпадения и выбирает первый результат. Курсор над прежней позицией узла не переключает панель на посторонний инструмент. Escape сохраняет сброс выбора при последующих обновлениях каталога.
- Пустой каталог, один инструмент и 30+ записей не требуют особого состава данных. Поиск использует ту же функцию и правила, что каталог.

## Движение

| Элемент       | Поведение                                                 | Время                           |
| ------------- | --------------------------------------------------------- | ------------------------------- |
| Hero и секции | Однократное последовательное появление                    | 450–600 мс                      |
| Узлы          | Появление, spring-like hover/press                        | 250–450 мс                      |
| Связь         | Подсветка и направленный световой поток к выбранному узлу | 220 мс; цикл 1,8 с              |
| Информация    | Crossfade без изменения размера панели                    | 120–220 мс                      |
| Каталог       | Появление, уход и FLIP-перестановка                       | 200–380 мс; появление до 540 мс |
| Навигация     | Индикатор, ширина sidebar и переход страницы              | 150–280 мс                      |
| Фон ядра      | Медленное изменение прозрачности и масштаба               | 5–6 с                           |

Основное движение использует transform/opacity; небольшая SVG-связь меняет stroke-dashoffset. Нет частиц и постоянного вращения. Кнопка паузы останавливает фоновое движение и поток связи. IntersectionObserver и visibilitychange приостанавливают их вне экрана и в скрытой вкладке без вычислений на каждом кадре. `prefers-reduced-motion` отключает фон, задержки и продолжительные переходы.

## Запуск

Запуск описан в [UI_REDESIGN.md](UI_REDESIGN.md#локальный-запуск). И в разработке, и в сборке используются реальные API и авторизация из `dev`. Тестовые сервисы и обход входа удалены. Backend, Kubernetes, Docker/compose, CI/CD и API-клиенты совпадают с `dev`; итоговый diff ветки ограничен `frontend/`.

MTS Text / MTS Extended загружаются через `/brand-fonts/*.woff2` с учётом base-пути. Пять используемых WOFF2-файлов хранятся в `public/brand-fonts/`, включены в Git и поставляются в сборке frontend. Исходная папка `mts_shrift/` и бренд-гайды остаются вне Git.

## Проверки

```powershell
npm.cmd run check
npm.cmd run build
npm.cmd exec playwright -- test --config playwright.signal.config.ts
npm.cmd run security
```

Chrome: 1440×900, 1920×1080 и 390×844. Frontend использует обычные HTTP-сервисы; изолированные Playwright-фикстуры существуют только в автотестах, как в `dev`. Доступность удалённого backend и модели этим не проверяется.

Проверены hover/focus узлов, Tab/стрелки/Escape, touch, полный проход по каталогу в обе стороны, открытие Copilot, пауза, уход со страницы, reduced motion, отсутствие перекрытий и стабильность crossfade. Покрыты 0, 1, 2, 5, 6, 30, 36, 80 и 100 инструментов; поиск вне пятёрки; статусы и удаление из API; фильтры и grid/list; Command Palette; обязательный вход/выход; polling и ошибки; чат с историей/удалением и Embedded UI. Загрузка обоих шрифтов подтверждается HTTP 200 и FontFace loaded; проверяются ошибки JavaScript и консоли.

Существующая high-уязвимость `undici` находится в dev-зависимостях; lock-файл не менялся.

## Скриншоты и кадры

`.artifacts/xops-signal-polish/` в корне репозитория игнорируется Git:

- `before/`, `after/`: одинаковые данные и три размера, общий вид и выбранный узел Signal; `signal-hero-*` — отдельные снимки исправленного блока.
- `index.html`: сравнение до/после с переключением размера и состояния.
- `counts/`: крайние размеры каталога и поиск в большом ответе API.
- `motion/index.html`: последовательность кадров с включёнными анимациями — смена узлов и информации, подсветка связи, поиск, фильтры, список и hover карточек.

После первого просмотра исправлено растягивание hero при выборе Copilot, вынесена подпись верхнего узла из области ядра, улучшены описание и кнопка открытия на мобильном. Финальная проверка по Web Interface Guidelines охватывает семантику, клавиатуру, контраст, focus, URL, переполнение и reduced motion. Исходные снимки сохранены отдельно.
