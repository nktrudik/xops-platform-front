# XOps Signal

Развитие реального интерфейса в `feature/ui-redesign-v2`. Backend, HTTP-контракты и CI/CD не менялись. Зависимости не добавлялись.

## Композиция и данные

- `CatalogHero.vue`: графитовая верхняя секция высотой 270 px на desktop, поиск, фактические счётчики.
- `CatalogSignal.vue`: SVG/CSS-пространство доступных Copilot. До шести узлов из текущего каталога, остальные учтены в подписи. Это обзор инструментов, а не граф зависимостей между внутренними системами. Hover и клавиатурный фокус раскрывают информацию; ссылка ведёт на существующий маршрут Copilot.
- `CopilotCollection.vue`: сетка на 1–4 колонки и компактный список. Компонент отвечает за появление и перестановку, `CopilotCard.vue` — за содержимое и взаимодействие карточки.
- `CommandPalette.vue`: нативный modal dialog, Ctrl+K / Cmd+K, стрелки, Enter, Escape. Поиск по тому же каталогу и маршруты платформы. Недоступные инструменты не открываются. Закрытая палитра не создаёт скрытые списки в DOM.
- `AppSidebar.vue`: сворачивание до 80 px, подписи инструментов доступны через title/aria-label, активный индикатор движется вслед за разделом. На мобильном остаётся модальное меню.
- Общие токены и панель инструментов связывают каталог, чат и Embedded UI. Чат, история и интеграция iframe сохраняют существующую логику.

Имена, статусы, счётчики и форматы на рабочих экранах берутся из API. Фильтры и вид сохраняются в URL. Для большого каталога сохранён `content-visibility: auto`.

## Движение

| Элемент         | Поведение                                                       | Время                                  |
| --------------- | --------------------------------------------------------------- | -------------------------------------- |
| Верхняя секция  | Однократное появление текста и красной дуги                     | 600–650 мс                             |
| Узлы            | Появление с небольшим последовательным сдвигом                  | До 625 мс суммарно                     |
| Карточки        | Появление, FLIP-перестановка, удаление из выдачи                | 180–280 мс; первое появление до 525 мс |
| Hover/press     | Подъём, красная линия, поворот действия, обратная связь нажатия | 150–240 мс                             |
| Навигация       | Ширина sidebar, активный индикатор, переход страницы            | 120–250 мс                             |
| Command Palette | Появление диалога                                               | 200 мс                                 |

Основное движение использует transform/opacity. Ширина sidebar меняется для реального перераспределения рабочего пространства; короткая SVG-анимация меняет stroke-dashoffset. Постоянного декоративного движения нет. `prefers-reduced-motion` отключает длительность и задержки, а также повторы. Состояния загрузки сохраняют текстовое обозначение.

## Локальный просмотр

Текущий локальный preview: `http://localhost:5173/`. Запуск и переключение между реальным API и изолированным frontend preview описаны в [UI_REDESIGN.md](UI_REDESIGN.md#локальный-запуск).

`VITE_AUTH_DISABLED=true` разрешён только в dev. Он включает тестовый каталог и чат в памяти из `src/preview/services.ts`. В production это условие всегда false, динамический импорт и данные preview исключаются из сборки. Тестовый режим не обращается к backend и не подключает удалённые Embedded-приложения.

MTS Text и MTS Extended загружаются через существующие `/brand-fonts/*.woff2`; добавлен preload основных начертаний с учётом base path. Локальный serve-плагин читает имеющиеся игнорируемые шрифты. Файлы шрифтов и бренд-гайдов не копируются в Git или dist.

## Проверки

```powershell
npm.cmd run check
npm.cmd run build
npm.cmd exec playwright -- test --config playwright.signal.config.ts
npm.cmd run security
```

Chrome проверяет 1440×900, 1920×1080 и 390×844. В конфигурации отключён dev-preview: авторизация, каталог, чат и Embedded проверяются через реальные сервисы frontend с HTTP-фикстурами Playwright. Это проверка frontend по существующему контракту; доступность удалённого backend и модели не проверяется.

Покрыты: вход/выход; фильтры и поиск; polling и ошибки; 0, 1, 6, 30 и 80 Copilot; Cmd/Ctrl+K и клавиатура; сохранение и удаление истории; отправка сообщений; открытие и повторная загрузка iframe; reduced motion. Проверяются HTTP 200 для обоих семейств шрифтов и состояние FontFace `loaded`. Для списка проверяется фактическая геометрия карточек.

`npm audit` сообщает о существующей high-уязвимости `undici@7.30.0` в dev-зависимостях. Lock-файл не менялся.

## Материалы визуальной проверки

В корне репозитория: `.artifacts/xops-signal/` (игнорируется Git).

- `home-{desktop,widescreen,mobile}.png` и `*-viewport.png` — полная главная и первый экран.
- `catalog-*`, `chat-*`, `embedded-*`, `command-*` — соответствующие рабочие экраны.
- `count-{0,1,6,30}-*` — крайние размеры каталога.
- `motion/index.html` — галерея последовательных кадров естественной анимации: вход, фокус узла, hover карточки, поиск, фильтрация, сетка → список, Command Palette и свёрнутое меню. При съёмке этих кадров анимации не отключаются.

После первого просмотра уменьшена высота верхней секции и отступы перед каталогом, ограничено число узлов для читаемости на мобильном. По кадрам движения найден и исправлен неверный scoped CSS списка: карточки теперь занимают всю строку и выравниваются по контейнеру. Финальный UX-аудит по Web Interface Guidelines охватил клавиатуру, focus, семантику, переполнение, состояние URL и reduced motion.
